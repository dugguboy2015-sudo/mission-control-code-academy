Finding the Story in the Numbers

Loading data is the easy half. The interesting half is asking it questions — what's normal, what's unusual, which group wins, what changed — and answering with evidence instead of a hunch. Field Manual

The Middle of the Data: Mean and Median

The mean (average) adds everything and divides by how many there are. The median is the middle value once sorted — half the data is above it, half below.

PYTHON
def mean(values):
    return sum(values) / len(values)

def median(values):
    ordered = sorted(values)
    middle = len(ordered) // 2
    if len(ordered) % 2 == 1:
        return ordered[middle]
    return (ordered[middle - 1] + ordered[middle]) / 2

print(mean([2, 4, 9]))     # 5.0
print(median([2, 4, 9]))   # 4
WHAT JUST HAPPENED // is whole-number division, so middle is a valid index. With an even count there are two middle values, so the median is their average. Why have both? One huge outlier (a 2,000-point fluke) drags the mean up a lot but barely moves the median — when they disagree, something unusual is in your data.

Group By: One Total per Category

"Total minutes per game" is the most common question in all of data work. A dictionary does it in one loop.

PYTHON
minutes_by_game = {}
for s in GAME_LOG:
    game = s["game"]
    minutes_by_game[game] = minutes_by_game.get(game, 0) + s["minutes"]

for game, total in minutes_by_game.items():
    print(game, total)
WHAT JUST HAPPENED .get(game, 0) starts each new game at 0 the first time it appears, then keeps adding. The same pattern counts things (+ 1 instead of + minutes) or collects lists of scores per game (.setdefault(game, []).append(score)) so you can average each group.

A Chart Made of Text

You don't need a charting library to see a pattern. Multiplying a string repeats it:

PYTHON
for game, total in minutes_by_game.items():
    bar = "#" * (total // 10)
    print(f"{game:12} {bar} {total}")
WHAT JUST HAPPENED "#" * 17 is seventeen hashes — one per ten minutes here. {game:12} pads the name to 12 characters so the bars line up. Crude, but your eye spots the biggest bar instantly, which is the whole point of a chart.
THE STORY RULE A finding is one sentence + one number + an honest limit. "Code Quest gets the highest average score (157.5) — but we only have 4 sessions per game, so this could change." Data shows what happened together, not what caused it: long sessions and high scores appearing together doesn't prove that playing longer makes you score higher.

⚠ COMMON MISTAKES

  • Taking the "middle" of an unsorted list — the median only means something after sorted().
  • Averaging the averages of groups with different sizes — weight by the number of items, or average the raw values.
  • Claiming a cause from a pattern. "Happened together" is correlation; proving cause needs an experiment.
  • Reporting a finding from tiny data as if it were certain — always say how many examples you had.
