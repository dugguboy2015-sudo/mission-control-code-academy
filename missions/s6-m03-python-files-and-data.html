Field Manual

Opening a File For Real: with open(...)

Python's standard pattern for reading a file is the with statement — it opens the file, hands it to you, and guarantees it gets closed automatically afterward, even if an error happens partway through.

PYTHON
with open("mission_log.txt", "r") as f:
    contents = f.read()

print(contents)

# f is automatically closed here, even if something above crashed
WHAT JUST HAPPENED "r" means "read mode." as f gives the open file a name to work with inside the indented block. The instant that block ends — for any reason — Python closes the file for you. Forgetting to close a file manually is a classic bug in other languages; with makes that mistake structurally impossible.

while Loops — Repeat Until a Condition Changes

A for loop repeats once per item in something. A while loop repeats as long as a condition stays True — useful when you don't know in advance how many times you'll need to loop.

PYTHON
fuel = 100
jumps = 0

while fuel > 20:
    fuel -= 15
    jumps += 1
    print(f"Jump {jumps}: fuel now at {fuel}")

print(f"Stopped after {jumps} jumps — fuel too low to continue safely.")
WHAT JUST HAPPENED Each pass checks fuel > 20 BEFORE running the block — the moment it's false, the loop stops, without needing to know ahead of time exactly how many jumps that would take. This is the classic danger zone for beginners too: if nothing inside the loop ever changes the condition, you've written an infinite loop that never stops.

Splitting Lines and Fields

Raw text data is almost always line-based, with fields separated by a character like a comma (a CSV — comma-separated values). Two string methods do almost all the work: .splitlines() breaks text into a list of lines, and .split(",") breaks one line into a list of fields.

PYTHON
raw_text = """date,event,fuel_used
2087-03-01,launch,40
2087-03-02,orbit_insertion,15
2087-03-03,docking,8"""

lines = raw_text.splitlines()
print(lines[0])   # 'date,event,fuel_used' — the header row

first_data_row = lines[1].split(",")
print(first_data_row)  # ['2087-03-01', 'launch', '40']
WHAT JUST HAPPENED """triple quotes""" let a string span multiple lines directly in your code — handy for sample data. .splitlines() turns that block into one list entry per line. .split(",") then turns one line into a list of its individual comma-separated values, still all strings — "40", not the number 40, which matters for the next step.

From Raw Text to a List of Dictionaries

Combine everything so far — .splitlines(), .split(","), a loop, and int() to convert text to a real number — and raw CSV text becomes the exact list-of-dictionaries shape from Mission 6.2.

PYTHON
raw_text = """date,event,fuel_used
2087-03-01,launch,40
2087-03-02,orbit_insertion,15
2087-03-03,docking,8"""

lines = raw_text.splitlines()
header = lines[0].split(",")

log_entries = []
for line in lines[1:]:
    values = line.split(",")
    entry = {
        "date": values[0],
        "event": values[1],
        "fuel_used": int(values[2]),
    }
    log_entries.append(entry)

print(log_entries)
print(f"Total fuel: {sum(e['fuel_used'] for e in log_entries)}")
WHAT JUST HAPPENED lines[1:] skips the header row using the slicing you learned in Mission 6.2. int(values[2]) converts the text "40" into the real number 40 — without it, sum() further down would try to add strings together and crash. This exact pipeline — read, split, convert, build a list of dicts — is the backbone of real-world data processing in Python.

Writing a File For Real

Writing follows the same with open(...) pattern, just with mode "w" instead of "r".

PYTHON
summary_lines = ["Total fuel used: 63", "Events logged: 3"]

with open("summary.txt", "w") as f:
    for line in summary_lines:
        f.write(line + "\n")
WHAT JUST HAPPENED "w" mode creates the file if it doesn't exist, and — this is important — completely erases and replaces it if it does. f.write() does not add a newline for you automatically, unlike print(), which is why "\n" is added manually after each line.

Debrief / Cheat Sheet

with open(f, "r") as f:Open a file for reading, auto-closed after
with open(f, "w") as f:Open a file for writing (erases existing contents)
f.read()Get the whole file as one string
f.write(s)Write a string — no automatic newline
.splitlines()Break text into a list of lines
.split(",")Break one line into fields
while condition:Repeat until the condition is False
int(text)Convert text to a real number

⚠ COMMON MISTAKES

  • Writing a while loop where nothing inside ever changes the condition — an infinite loop that freezes the program.
  • Forgetting that everything from .split(",") is still text (a string), and trying to do math on it before converting with int() or float().
  • Opening a file with "w" mode when you meant to only read it — this silently erases the file's previous contents.
  • Forgetting to skip the header row (lines[1:]) and accidentally trying to process the column names as if they were data.
